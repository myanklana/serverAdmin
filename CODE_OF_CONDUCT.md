# Código de conduta

Participe de forma respeitosa. Não toleramos assédio, discriminação, ataques pessoais ou
divulgação de informações privadas de terceiros. Discordâncias técnicas são bem-vindas;
ataques a pessoas, não.

Os mantenedores podem editar ou remover contribuições que violem este código e banir quem o
violar repetidamente. Para denunciar, use o contato descrito em [SECURITY.md](SECURITY.md).

Este texto segue o espírito do [Contributor Covenant 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).
